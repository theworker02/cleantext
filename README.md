# cleantext

Clean digests and text fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/cleantext/

## Install / run

```bash
git clone https://github.com/theworker02/cleantext.git
cd cleantext
node src/cli.js
node --test
```
